# Forex Sniper

An educational EUR/USD market-analysis project. The first version will collect historical market data, calculate technical indicators, and generate testable analysis signals. It will not place live trades.

## Project stages
1. Set up the Node.js project.
2. Download historical EUR/USD candles.
3. Calculate EMA, RSI, MACD, and ATR.
4. Build and backtest signal rules.
5. Add scheduled GitHub Actions runs and safe notifications.

## Requirements
- Node.js 20 or newer
- npm

## Setup
```bash
npm install
npm run check
npm start
```

## Security
Never commit API keys, passwords, broker credentials, or `.env` files.

## Disclaimer
For research and education only. Signals are not financial advice. Backtest results do not guarantee future performance.
